# docs — 문서 안내

## 목적
Fast Track 개발에 필요한 요구사항, 작업 목록, 검증 기준, 장기 정책을 최소 파일로 관리한다.

## 현재 문서
- [공통 결정 문서](decisions.md): 확정/검토/미결정 상태 및 이유
- [v0.1 문서 인덱스](v0.1/README.md)
- [v0.1 사양서](v0.1/spec.md): 제품 동작 및 상태 전이의 단일 기준
- [v0.1 작업 목록](v0.1/tasks.md): FT 작업 ID, 범위, 수행 상태
- [v0.1 검증 기준](v0.1/validation.md): 수락 기준 및 실험 결과(현재 미실행)

## 관리 방법
- 사용자 승인 요구사항은 `v0.1/spec.md`에 반영한다.
- 중요 결정은 `decisions.md`에 확정/검토 상태를 나눠 기록한다.
- 구현 단위와 진행 상태는 `tasks.md`에서 관리한다.
- 자동 테스트·실기 확인 결과는 `validation.md`에 기록한다.
- 새 버전은 `docs/v0.2/`처럼 버전별 폴더를 만들고 README를 함께 추가한다.
- 기존 사양을 중복 복사하거나 검증하지 않은 결과를 기록하지 않는다.
