# v0.1 — Fast Track MVP

## 목적
6명 밴드의 18곡 비밀투표를 실제 휴대전화 브라우저에서 공정하게 수행할 수 있는 첫 번째 웹 버전.

## 문서
- [spec.md](spec.md) — 확정 규칙, 사용자 흐름, API/데이터 요구사항, 미결정 사항
- [tasks.md](tasks.md) — FT-001부터의 구현·검증 작업 체크리스트
- [validation.md](validation.md) — 수락 테스트, 비밀성/마감/동시성 점검

## 현재 상태
문서 작성 완료, 구현·빌드·자동 테스트·실기·서비스 배포는 모두 미착수.

## 운영 원칙
- 기능 추가 제안은 `../decisions.md`에 검토 상태로 기록한다.
- 각 작업은 범위·완료 기준을 만족할 때만 완료 처리한다.
- 보안/결과 공개 검증이 통과하지 않으면 운영 배포하지 않는다.
