## 미결정 항목 해결 후 추가할 검증
- 동점 처리 및 재투표.
- 5/6 종료 후 연장/재개 정책과 변경 이력.
- 동일 곡 중복 추천 처리.
- 토큰 재발급에 따른 기존 투표 보존/무효화.
- DB 관리자에 대한 강한 익명성(암호화)을 요구할 경우 키 관리/복호화 시점.

## 실기 체크
- Android Chrome / 카카오톡 인앱 브라우저
- iOS Safari / 카카오톡 인앱 브라우저
- 데스크톱 Safari/Chrome
- 링크 복사, 재접속, 재제출, 비정상 네트워크 복구
- 발표 시각이 지나도 5/6이면 실명 선택·득표가 보이지 않는지 확인
- 발표 조건 충족 후 일반 URL에서 **이름별 6개 선택과 득표 집계가 모두 공개**되는지 확인
