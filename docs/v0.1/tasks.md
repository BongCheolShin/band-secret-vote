## 작업 갱신 규칙
- 작업은 `TODO / IN_PROGRESS / DONE / BLOCKED` 중 하나로 관리한다.
- 한 작업을 `DONE`으로 변경할 때 커밋/PR 또는 실행 증거 및 검증 방법을 함께 남긴다.
- 사용자 합의 없는 기능 추가, 투표 구조 변경, **공개 조건 충족 전의** 중간 결과 공개는 금지한다.
- 발표 후 실명별 최종 선택을 숨기거나 영구 익명으로 표시하지 않는다. 첫 제출·수정 제출 전에 공개 예고문을 제공한다.
