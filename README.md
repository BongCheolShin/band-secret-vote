# Band Secret Vote (밴드 공연곡 비밀투표)

이따위밴드 2027년 상반기 공연곡 선정을 위한 모바일 비밀투표 웹 애플리케이션 서비스 저장소입니다.

- **투표 사이트 바로가기:** [https://BongCheolShin.github.io/band-secret-vote/](https://BongCheolShin.github.io/band-secret-vote/)
- **공연 주제:** 신해철 (18개 후보곡 중 추천자별 1곡씩 총 6곡 선정)
- **투표 기간:** 2026-11-12 ~ 2026-11-13 (KST)
- **안내:** 투표 진행 중에는 비공개로 보호되며, 마감 및 전원 참여 완료 시 결과 페이지를 통해 최종 선정곡과 투표 내역이 공개됩니다.
